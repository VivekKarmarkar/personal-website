# The Show

*A story about how websites are built and delivered to the world — told through theater, family, and a courier with a trunk.*

*Written January 30, 2026*

---

## Part 1: The Show

HTML was the oldest of three brothers. Serious. Methodical. He built stages. Give him a hall and he'd frame every platform, every doorway, every staircase. You could walk through his work and know exactly where everything was. But you wouldn't want to — it was bare wood and nails. Functional. Ugly. He didn't care. "Without me," he'd say, "you're painting air."

CSS, the middle brother, couldn't stand the ugliness. He'd arrive the morning after HTML finished, run his hands along the bare wood, and transform it. Dark velvet curtains. Amber spotlighting. Seats that curved just so. He could make a cheap stage feel like a palace. But nothing on it moved. His stages were photographs — stunning, frozen.

JavaScript was the youngest. Loud. Restless. He wired the trapdoors, rigged the pulleys, built the machines that made actors fly. When the audience gasped, it was his doing. Smoke, light cues, moving sets, falling rain — all JavaScript. "They come for me," he'd say. The brothers would argue about this over dinner every night. Forty years they argued. Forty years they never worked apart.

But the shows were getting bigger. Vivek, a physicist turned director, had ideas the brothers couldn't build fast enough. Interactive simulations. Live demonstrations. Seven shows running simultaneously, each one different.

So the brothers' children stepped in.

React, JavaScript's eldest son, watched his father build the same contraptions from scratch for every scene. "This is madness," he muttered. He invented modular rigs — a trapdoor mechanism that could be lifted out of one show and dropped into another. Build it once. Use it in the Feynman show, the Neural Net show, the Sequence Convergence show. Same rig, different context. His father pretended not to be impressed. He was.

TypeScript, JavaScript's second son, was the anxious one. He followed his father around with a notebook. "That lever — what does it control? Write it down. Label it. If someone pulls the wrong one during the show—" JavaScript would wave him off. But the Electromagnetic Generator show — the most complex rigging they'd ever done — ran without a single misfire. TypeScript allowed himself a small smile.

Tailwind was CSS's daughter. She watched her father spend three hours mixing a precise shade of dark amber for a single curtain. She developed a catalog — hundreds of pre-mixed colors, fabrics, and arrangements, each with a code. `bg-gray-900` meant that exact dark background her father used in every show. He could now do in seconds what took hours. He grumbled about craftsmanship. He used the catalog every day.

JSX was the wild card — she worked in the space between HTML and JavaScript, writing set designs and rigging instructions in the same breath. The purists hated her. Everyone used her.

But here was the problem.

The audience didn't speak apprentice. The audience — every audience, in every city, since the beginning of theater — only understood three languages: structure, beauty, and movement. HTML, CSS, JavaScript. That was it. That was all they'd ever understand.

So the brothers hired Vite.

Vite was a quiet woman who arrived after everyone else left. Every night, she'd sit alone in the empty hall and rewrite the entire show. Every modular rig React built — she'd unfold it into her father-in-law's original handcraft. Every TypeScript label — she'd dissolve it, leaving just the mechanism. Every Tailwind code — she'd expand it back into CSS's full brushwork. Every JSX hybrid — she'd separate it cleanly into structure and movement.

By morning, a folder sat by the door. Marked `dist`. Inside: a show written entirely in the three brothers' original language. As if the children had never existed. As if every piece had been handcrafted the old way.

Vite never took a bow. The audience never knew her name. The show worked. That was enough.

But it played in one hall. In one town. The only people who'd ever see it were the ones who came to Vivek's building and knocked on the door.

---

## Part 2: The Tour

The show was ready. It sat in Vivek's hall. He could watch it every night. Nobody else could.

He packed the entire production into a trunk and gave it to a courier. "Take this to the capital." The courier — `git push` — carried the trunk through roads, bridges, mountain passes. The trunk arrived at a massive stone vault in the capital, owned by the wealthiest family in the country: Microsoft. The vault was called GitHub. Thousands of creators stored their work there. Armed guards. Fireproof walls. Vivek could burn down his own hall and the show would survive inside that vault.

But the vault just *stored* things. No one could watch a show inside a vault.

A producer named Vercel heard about the work. She sent a team to the vault, unlocked it, and pulled out the trunk. She hired a temporary crew — stagehands, riggers, painters — and told them: "Build this once. Get it right." The crew assembled the show exactly as Vite had written it — plain structure, plain beauty, plain movement. When they finished, Vercel made copies. Hundreds of copies. She sent them to stages she owned in every major city — Mumbai, London, Virginia, Tokyo, Sao Paulo. Then she let the temporary crew go. They'd done their one job. They would never assemble again.

A girl in Pune heard about the show. She walked into her local stage — her browser — and sat down. The stage didn't create anything. No actors performed. No crew built sets. The stage simply handed her the script, the designs, the rigging instructions, and *her own mind* brought it to life. Her eyes did the rendering. Her imagination ran the simulations. The blocks in the Feynman show bounced inside *her* head. The neural network lit up on *her* screen.

Vivek's hall was dark. The temporary crew was gone. The vault just sat there. The stages in Mumbai and London held nothing but copies. Everything — all the computation, all the movement, all the life — happened inside the audience.

That was the strange miracle of it. A show that performed itself, differently, inside every person who watched it.

## Part 3: The Growth

Months passed. The show grew.

A man in Berlin watched the show and wanted to ask a question — something that required a private answer. But the script was public. Everyone who attended could read every word. You couldn't hide a secret inside a script.

So Vercel built a small locked room backstage at each of her stages. Inside sat a single person with a sealed envelope — the answer. The room stayed dark and empty until someone knocked. When they did, the person inside would read the question through a slot, check the sealed envelope, and slide the answer back. Then the lights went off. The person waited. This was a serverless function. It existed only in the moment of the knock.

The envelope held Vivek's most private things — his key to the Anthropic library, where an oracle could answer questions about physics. The audience could *ask* the oracle through the locked room. But they could never see the key. They could never walk into the library themselves.

Then Vivek wanted to remember his audience. Who came back? What did they ask? What did they struggle with? A show that forgets its audience every night isn't a relationship — it's a performance.

He hired Supabase — a woman with a perfect memory who ran a records office in a building across town. Every time someone knocked on the locked room, the person inside would also send a note to Supabase: "The man in Berlin asked about conservation of energy. Third visit." Supabase filed it. Never forgot.

It worked. Until it didn't.

One evening, a thousand people knocked at the same time. Vercel, efficient as always, opened a thousand locked rooms — one for each person. Each room sent a note to Supabase. But Supabase had one door. A thousand messengers arrived simultaneously, all trying to push through a single entrance. The line stretched around the block. Some messengers gave up. Some were turned away. The audience received no answers.

Vercel wasn't the problem — she could open rooms forever. Supabase wasn't the problem — she could file forever. The problem was the *distance* between them. A thousand messengers crossing town, fighting for one door.

Vivek saw the solution. He rented his own building. He put the locked room and the records office on the same floor. Same hallway. Three steps apart. No messengers. No crossing town. No single door bottleneck. A knock in the locked room, a whisper down the hall, an answer filed and returned. All under one roof.

The building cost more than everything else combined. He didn't need it when ten people watched. He didn't need it when a hundred came. He needed it when a thousand showed up at once and the architecture he'd grown into — piece by piece, stage by stage — finally couldn't hold.

He looked back at where it started. A physicist with a show in an empty hall. A courier. A vault. A producer. Stages around the world. A locked room. A records office. And finally, his own building.

All of it because he'd run `git push` one afternoon and the courier carried his trunk to the capital.

## The Cast

| Character | Role in the Story | What They Really Are |
|-----------|------------------|---------------------|
| HTML | Oldest brother — builds stages (structure) | HyperText Markup Language — page structure |
| CSS | Middle brother — paints and decorates (beauty) | Cascading Style Sheets — visual styling |
| JavaScript | Youngest brother — wires movement and life | The programming language of the web |
| React | JavaScript's son — modular rigs | JavaScript UI library (reusable components) |
| TypeScript | JavaScript's cautious son — labels everything | JavaScript with enforced type checking |
| Tailwind | CSS's daughter — shorthand catalog | CSS utility class library |
| JSX | The wild card — blurs structure and movement | HTML-like syntax inside JavaScript |
| Vite | The quiet translator — rewrites everything | Build tool that compiles to HTML/CSS/JS |
| `dist` folder | The finished script by the door | Compiled output of `npm run build` |
| Vivek's hall | The one-table restaurant | `localhost` — your laptop as server |
| The courier | Carries the trunk to the capital | `git push` — sending code to GitHub |
| The vault (GitHub) | Microsoft's stone vault | GitHub — code storage (owned by Microsoft) |
| Vercel | The producer | Hosting platform that builds and distributes |
| The temporary crew | Assembles the show once | Vercel's build server (runs once per deploy) |
| Stages worldwide | Mumbai, London, Virginia, Tokyo | CDN — Content Delivery Network servers |
| The girl in Pune | Watches the show in her own mind | A user's browser (runs everything locally) |
| The locked room | Backstage, opens only when knocked | Serverless function (holds API keys) |
| The sealed envelope | The secret inside | API keys (Anthropic, database credentials) |
| The Anthropic library | The oracle that answers questions | Anthropic's API / Claude |
| Supabase | The woman with perfect memory | Managed database service |
| The single door | Supabase's bottleneck | Database connection pool limit |
| Vivek's own building | Everything under one roof | AWS server (database + backend co-located) |

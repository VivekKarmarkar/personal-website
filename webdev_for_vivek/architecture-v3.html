None are understood by browsers — Vite translates everything back to the three foundational languages.

WHY CAN'T THE BROWSER RUN JAX?
JAX needs XLA compilation — a real server with Python, NumPy, and JAX installed. Your browser only runs JavaScript. So MyBinder spins up a temporary virtual machine in the cloud (a real computer in a data center) with JAX installed. Your browser connects to it via WebSocket. Code runs there. Results stream back.
Right now, your laptop is both the server and the client. Vite serves files at localhost:5173, your browser downloads and runs them — all on the same machine, no internet needed. But two things already cross the internet: MyBinder runs JAX code on a temporary cloud server (your browser can't do XLA compilation), and YouTube streams embedded video from Google's servers. The sims run locally. The heavy compute and video happen elsewhere.

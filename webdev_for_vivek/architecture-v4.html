The Web Languages

Every website is built with three foundational languages. Browsers understand nothing else.

YOU WRITE
JSX — convenience syntax
Looks like HTML, lives inside JavaScript.
Browsers can't read it.
React — JavaScript library
Reusable UI components. Uses JSX.
Like NumPy is to Python.
TypeScript — JS + type enforcement
Like Python type hints, but blocks you
if the types are wrong.
Tailwind — CSS library
Shorthand classes like bg-dark-bg.
Like NumPy is to Python.
⚡
VITE
The Translator
JSX → JavaScript
Tailwind → CSS
TypeScript → JavaScript
BROWSER UNDERSTANDS
🦴
HTML — Skeleton
What's on the page. The entry point.
References the CSS and JS files.
🎨
CSS — Skin
How it looks: colors, fonts, layout.
Why your site is dark with orange accents.
🧠
JavaScript — Brain
What it does: clicks, animations, sims.
All 7 sims run as JS in the browser.
Analogy: NumPy is to Python as React is to JavaScript as Tailwind is to CSS.
These three are foundational. Not built on anything. Every framework compiles down to them.
Browsers speak exactly three languages: HTML, CSS, and JavaScript. You write in convenience tools — React/JSX, Tailwind, TypeScript — and Vite translates everything back to the three languages browsers actually speak.
